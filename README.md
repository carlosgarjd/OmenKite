# OmenKite

OmenKite is a containerized predictive analytics platform that enables data processing and auto-scaling management within a unified framework.

The key benefits of using OmenKite include:

- OmenKite is a containerized predictive

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/OmenKite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
